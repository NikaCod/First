## Git. Основы

### Зачем нужен Git?

#### Почему не флешка?

1. Флешка - потенциальный разносчик вирусов
2. Личные данные с флешки случайно могут попасть на чужой компьютер
3. Антивирус ОС может удалить данные с флешки
4. Флешка может потеряться или сломаться

#### Почему не облако типа Yandex Диск или Google Диск?

1. Облако не контролирует версии данных
2. Своё облако на чужом компьютере - это риск утечки личных данных
3. Для работы с облаком на чужом компьютере необходим браузер, а это не безопасно
4. Нет надёжной фильтрации типов файлов для загрузки и хранения в облаке

#### Преимущества Git

1. Трудно потерять свои проекты
2. Легко отслеживать версии проекта
3. Легко делиться с другими людьми своими проектами
4. Легко разработать проекты совместно с другими людьми (в команде)
5. Git по умолчанию интегрирован во многие популярные средства разработки, т.к. VSCode
6. В Git можно создать веб-страницы с описанием своих проектов
7. Многие Git-сервисы предоставляют возможность автоматизации сборки ваших проектов

#### Основные состояния git-репозитория

1. **Состояние** - `git status` - показать состояние текущего репозитория
2. **Инициализация** - `git init` - превращение обычной папки в репозиторий
3. **Подготовка** (добавлены изменения) - `git add .` - добавление изменений
4. **Фиксация**, сохранение - `git commit -m 'Update README.md - fix'` - сохранение
5. **Синхронизации** с удалённым репозиторием - `git push` - сохранение на облачном сервисе, например `Gitflic.ru`
